# 8주차 실습 가이드: 나의 경험, AI를 만나 비즈니스가 되다

> 준비물: 7주차 브랜드 키트(`brand_kit.md`), "돈을 받고 도와줄 수 있는 일" 후보 3개, (선택) Claude API 키
> 소요 시간: 약 80분 · 결과물: 아이디어 점수표, 가격 계산, 1장 기획서, 사전 신청 랜딩페이지, 3분 발표 대본

## 0. 파일 구성

| 파일 | 하는 일 |
|---|---|
| `examples/my_ideas.json` | 내 포지셔닝, 아이디어 후보 3개와 점수, 가격 조건 (예시 → 내 것으로 바꾸기) |
| `examples/business_plan.py` | 점수화 → 1등 선택 → 가격 계산 → AI로 기획서·인터뷰 질문·랜딩 문구·발표 대본 생성 |
| `examples/offer_landing.html` | 사전 신청 랜딩페이지 (설정 한 곳만 바꾸면 내 페이지) |

환경 준비(파이썬, 선택 사항인 API 키, 연습 모드)는 [7주차 실습 가이드 1장](../week07/practice-guide.md#1-환경-준비-10분)과 같습니다.

## 1. 아이디어 후보 적기 (15분)

`my_ideas.json`을 열고 순서대로 바꿉니다.

1. `profile.positioning`: 7주차 포지셔닝 문장을 그대로 붙여 넣습니다.
2. `profile.experiences`: 증거(숫자)가 있는 핵심 경험 2~3개
3. `ideas`: 후보 3개. 각각 `title`(오퍼), `customer`(누구), `problem`(대상의 말투로 쓴 문제)
4. `scores`: 기준별 1~5점 (정수)

| 키 | 기준 | 5점이면 |
|---|---|---|
| `experience_fit` | 경험 적합도 | 내 경험 인벤토리에 숫자 증거가 있다 |
| `willingness_to_pay` | 고객 지불 의사 | 대상이 이미 이 문제에 돈을 쓰고 있다 |
| `ease_of_start` | 시작 용이성 | 이번 달, 혼자, 10만 원 이하로 시작 가능 |
| `time_available` | 시간 여건 | 지금 생활에서 충분히 시간을 낼 수 있다 |
| `ai_leverage` | AI 활용도 | AI로 준비 시간이 절반 이하로 줄어든다 |

5. `pricing`: 월 목표 부수입(원), 월 투입 가능 시간, 1회당 준비 시간, 진행 시간

> 점수는 혼자 매기지 말고 **짝꿍에게 "고객 지불 의사" 점수만 따로 매겨 달라고** 해 보세요. 내 점수와 다르면 그 이유가 좋은 토론거리입니다.

## 2. 실행 (5분)

```bash
cd docs/curriculum/week08/examples
python business_plan.py my_ideas.json
```

정상 실행 화면 (예시 데이터 기준):
```
1등 아이디어: 작은 회사 신입 90일 정착 코칭 (대표 1:1, 4회) (81.0점)
첫 가격: 1회 100,000원 · 월 목표까지 10회
결과 폴더: .../output
```

`output/` 폴더에 다음 파일이 생깁니다.

| 파일 | 내용 |
|---|---|
| `idea_scores.md` | 후보별 점수표와 순위 |
| `pricing.md` | 시간당 단가, 1회 가격, 월 목표까지 필요한 판매 횟수 |
| `business_prompt.txt` | AI에게 보낸 프롬프트 (연습 모드면 웹 AI에 붙여 넣기) |
| `business_plan.md` | 1장 기획서, 인터뷰 질문, 랜딩 문구, 발표 대본 |

### 막혔을 때

| 메시지 | 원인 | 해결 |
|---|---|---|
| `... 점수는 1~5 정수여야 합니다.` | 점수가 비었거나 `3.5`, `"4"`처럼 적음 | 따옴표 없는 1~5 정수로 |
| `'pricing' 항목이 없습니다.` | JSON에서 항목을 지움 | 예시 파일 구조를 다시 확인 |
| `월 목표 수입과 월 투입 시간은 0보다 커야 합니다.` | 0이나 음수 입력 | 현실적인 값으로 |

## 3. 결과 다듬기 (20분)

1. **점수표 검토**: 1등이 마음에 들지 않나요? 그렇다면 어떤 점수를 바꾸고 싶은지, 혹은 `business_plan.py`의 `WEIGHTS`(가중치)가 나와 맞지 않는지 생각해 봅니다. 가중치를 바꿔 다시 실행해 보세요.
2. **가격 검토**: 계산된 가격이 대상 고객에게 너무 비싸거나 싸다면, 진행 시간이나 상품 구성(1회 → 4회 패키지)을 바꿉니다.
3. **기획서 사실 확인**: `[직접 입력]` 칸을 채우고, AI가 지어낸 후기·수치가 없는지 확인합니다.
4. **인터뷰 질문 점검**: "~하시겠어요?" 같은 가정형 질문이 남아 있으면 과거 행동을 묻는 질문으로 바꿉니다.

## 4. 사전 신청 랜딩페이지 (20분)

1. `offer_landing.html`을 메모장(또는 VS Code)으로 엽니다.
2. `<script>` 안의 **`OFFER` 설정**만 `business_plan.md`의 랜딩페이지 문구로 바꿉니다.
   - 쉼표와 따옴표를 지우지 않도록 주의합니다.
3. 저장하고 브라우저로 열어 확인합니다.
4. 직접 사전 신청을 1건 넣어 보고, **운영자 메뉴 → 신청 목록 CSV 저장**으로 엑셀에서 열리는지 확인합니다.

### 실제로 공개할 때
- 이 페이지는 **수업용 시제품**입니다. 신청 정보가 내 브라우저에만 저장되므로, 공개할 때는 신청 버튼을 구글 폼·네이버 폼 링크로 바꾸고 운영자 메뉴 영역을 지웁니다.
- 개인정보는 **목적·항목·보관 기간**을 알리고 동의를 받습니다. (페이지의 동의 문구 참고)
- "월 300 보장" 같은 수익·효과 보장 표현은 쓰지 않습니다.

## 5. 3분 발표 준비 (15분)

1. `business_plan.md`의 발표 대본을 소리 내어 읽으며 **타이머로 시간을 잽니다.**
2. 3분이 넘으면 "문제" 부분을 줄입니다. 시연 시간(1분)은 지킵니다.
3. 시연 거리: 7주차 1페이지 프로필, 8주차 랜딩페이지, 8주 동안 AI로 만든 문서 중 1개
4. 마지막 문장은 **"제가 받고 싶은 도움은 ○○입니다"** 로 끝냅니다. (소개, 피드백, 인터뷰 대상 연결 등)

## 6. 완료 체크리스트

- [ ] 아이디어 3개를 점수화하고 1개를 골랐다
- [ ] 첫 가격과 3단 상품 구조(무료·저가·본상품)를 정했다
- [ ] 인터뷰 질문 7개를 과거 행동 중심으로 다듬었다
- [ ] 랜딩페이지에서 신청과 CSV 저장을 직접 해 봤다
- [ ] 3분 발표를 시간 안에 마쳤다
- [ ] 수료 후 30일 실행 계획 1주차 할 일을 달력에 적었다

## 7. 더 해보기 (도전 과제)

- `WEIGHTS`에 새 기준(예: `"joy": 0.1`, 내가 즐거운 일인가)을 추가해 보세요. `CRITERIA_LABELS`와 JSON 점수도 함께 추가해야 합니다.
- `calc_price()`로 "4회 패키지 10% 할인" 가격을 계산하는 함수를 추가해 보세요.
- `offer_landing.html`의 `--accent` 색을 7주차 프로필 페이지와 같은 색으로 맞춰 브랜드를 통일해 보세요.
