# 7주차 실습 가이드: 퍼스널 브랜딩 완성형

> 준비물: 노트북, 실습 ①에서 만든 경험 인벤토리 표, (선택) Claude API 키
> 소요 시간: 약 70분 · 결과물: `output/brand_kit.md`, `output/fact_check.md`, 1페이지 프로필 HTML

## 0. 파일 구성

| 파일 | 하는 일 |
|---|---|
| `examples/my_profile.json` | 내 경험 인벤토리 (예시가 들어 있음 → 내 것으로 바꾸기) |
| `examples/brand_kit.py` | 프로필로 프롬프트를 만들고, AI로 브랜드 키트를 생성하고, 사실 검증 리포트를 만든다 |
| `examples/profile_page.html` | 브랜드 키트 문구로 1페이지 프로필을 만든다 (브라우저에서 바로 열기) |
| `../common/ai_client.py` | AI 호출 공통 모듈. 키가 없으면 연습 모드로 동작 |

## 1. 환경 준비 (10분)

### 1-1. 파이썬 확인
```bash
python --version   # 3.10 이상이면 됩니다
```

### 1-2. (선택) 실제 AI로 실행하고 싶다면
```bash
pip install -r ../../requirements.txt
```
그다음 API 키를 **환경변수**로 넣습니다. 코드 파일에 키를 직접 적지 않습니다.

- Windows PowerShell: `$env:ANTHROPIC_API_KEY="발급받은 키"`
- macOS/Linux: `export ANTHROPIC_API_KEY="발급받은 키"`

키가 없거나 설치가 어렵다면 그냥 넘어가세요. **연습 모드**로 똑같이 실습할 수 있습니다.
일부러 연습 모드로 돌리고 싶으면 `MYAIEDU_MOCK=1`을 설정합니다.

## 2. 경험 인벤토리를 JSON으로 옮기기 (15분)

`my_profile.json`을 메모장(또는 VS Code)으로 열어 내 정보로 바꿉니다.

| 항목 | 뜻 | 예시 |
|---|---|---|
| `name` | 이름 또는 활동명 | 김현수 |
| `field` | 경력 분야 | 중소기업 인사·교육 |
| `career_years` | 경력 연수 (숫자) | 22 |
| `role` | 되고 싶은 역할 | 조직 적응 코치 |
| `target` | 돕고 싶은 대상 | 직원 10명 이하 회사 대표 |
| `problem` | 대상이 겪는 문제 (대상의 말투로) | 신입이 자꾸 그만두는 |
| `experiences` | 경험·증거·필요한 사람 (3개 이상 권장) | 표 참고 |
| `tone` | 말투 형용사 3개 | 신뢰감 있는, 따뜻한, 구체적인 |
| `banned_words` | 내가 쓰고 싶지 않은 표현 | 갓생, 레전드 |

주의할 점
- 따옴표(`"`)와 쉼표(`,`)를 지우지 않습니다. 마지막 항목 뒤에는 쉼표를 넣지 않습니다.
- 회사명·고객명·내부 수치는 넣지 않습니다. ("A사" ✕ → "중견 제조사" ○)

## 3. 브랜드 키트 생성 (10분)

```bash
cd docs/curriculum/week07/examples
python brand_kit.py my_profile.json
```

정상 실행 화면:
```
브랜드 키트를 만들었습니다: .../output/brand_kit.md
확인할 항목 2개: .../output/fact_check.md
```

### 막혔을 때

| 메시지 | 원인 | 해결 |
|---|---|---|
| `프로필에 빠진 항목이 있습니다: target` | JSON에 필수 항목이 비어 있음 | 해당 항목을 채운다 |
| `프로필을 읽지 못했습니다: Expecting ',' ...` | JSON 쉼표·따옴표 실수 | 오류에 나온 줄 번호 근처를 확인 |
| `[알림] AI 호출 실패(AuthenticationError)` | API 키가 틀림 | 키를 다시 설정하거나 연습 모드로 진행 |
| `python`을 찾을 수 없음 | 파이썬 미설치/경로 문제 | `py brand_kit.py my_profile.json` (Windows) |

## 4. 사실 검증과 고쳐 쓰기 (20분) ← 오늘의 핵심

1. `output/fact_check.md`를 엽니다. 자동 점검은 다음을 찾아 줍니다.
   - "최고", "유일", "1위" 같은 **근거 확인이 어려운 표현**
   - 내 프로필에 **없던 숫자** (AI가 지어냈을 가능성)
   - AI가 스스로 `(확인 필요)`로 표시한 문장
2. `output/brand_kit.md`를 열어 걸린 항목을 하나씩 고칩니다.
3. 자동 점검이 못 잡는 것은 **직접** 확인합니다.
   - [ ] 직함·자격증이 실제와 같은가
   - [ ] 내가 실제로 쓰는 말투인가 (소리 내어 읽기)
   - [ ] 전 직장 기밀이나 특정인이 드러나지 않는가
4. 마음에 들지 않으면 `tone`이나 `experiences`를 바꿔 다시 실행합니다. **3번 정도 반복**하면 내 말투에 가까워집니다.

### 연습 모드라면
`output/brand_kit_prompt.txt`의 내용을 전부 복사해 웹 AI(Claude, ChatGPT 등)에 붙여 넣으세요. 받은 답변을 `brand_kit.md`에 붙여 넣고 위 4단계를 그대로 진행합니다.

## 5. 1페이지 프로필 만들기 (15분)

1. `profile_page.html`을 더블클릭해 브라우저로 엽니다.
2. 왼쪽 입력칸에 브랜드 키트의 **한 줄 소개, 30초 자기소개, 콘텐츠 주제 기둥**을 붙여 넣습니다.
3. 오른쪽 미리보기를 확인하고, 브라우저 창을 좁혀 휴대폰 화면에서도 읽기 편한지 봅니다.
4. **완성본 HTML 복사** → 메모장에 붙여 넣기 → `profile.html`로 저장합니다.
5. (선택) 저장한 파일을 깃허브 페이지 등에 올려 링크를 만들고, 카톡 프로필에 연결합니다.

> 입력 내용은 브라우저에만 저장되고 어디에도 전송되지 않습니다. 연락처는 공개해도 되는 것만 적습니다.
