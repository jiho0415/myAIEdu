# 7주차 강의록: 퍼스널 브랜딩 완성형

> 대상: 4050 직장인 · 시간: 180분 (쉬는 시간 포함) · 단계: 자동화·발표
> 결과물: **나의 브랜드 키트 1세트** (한 줄 소개, 자기소개 3종, 프로필 문구, 콘텐츠 주제 3개, 1페이지 프로필 웹페이지)

---

## 1. 이번 주 학습 목표

수업이 끝나면 수강생은 다음을 할 수 있습니다.

1. 20년 안팎의 경력에서 **남에게 팔 수 있는 경험 자산**을 3개 이상 찾아낸다.
2. "나는 ○○에게 △△를 해 주는 사람"이라는 **브랜드 포지셔닝 문장**을 한 줄로 쓴다.
3. AI로 자기소개를 **상황별 3종(30초·1분·온라인 프로필)** 으로 만들고, 사실과 다른 과장을 스스로 걸러낸다.
4. 앞으로 꾸준히 쓸 **콘텐츠 주제 기둥 3개**와 첫 글 제목 5개를 정한다.
5. 실습 코드로 만든 문구를 **1페이지 프로필 웹페이지**에 담아 휴대폰으로 보여 줄 수 있다.

## 2. 지난 주와의 연결

| 주차 | 배운 것 | 7주차에서 쓰는 방식 |
|---|---|---|
| 2주차 | 프롬프트 공식(역할·맥락·작업·형식·제약) | 브랜드 키트 프롬프트의 뼈대 |
| 3~4주차 | 문서 초안 → 다듬기 | 자기소개 초안을 3번 고쳐 쓰기 |
| 5~6주차 | 홍보 문구·채널별 콘텐츠 | "나"를 상품으로 놓고 같은 방식 적용 |

> 강사 멘트: "지난 2주 동안 가게와 서비스를 홍보했죠. 오늘은 홍보할 상품이 **여러분 자신**입니다."

## 4. 개념 ①: 왜 지금 퍼스널 브랜딩인가

### 4-1. 4050 직장인의 현실
- 회사 명함이 사라지면 **"무슨 일 하셨어요?"** 에 한 문장으로 답하기 어렵다.
- 경험은 많은데, **남이 알아볼 수 있는 언어**로 정리된 적이 없다.
- 이직·재취업·강의·컨설팅·창업 모두 **"이 사람이 누구인지"** 부터 확인한다.

### 4-2. 퍼스널 브랜딩의 정의 (수업용)
> 퍼스널 브랜딩 = **누구에게(대상)** + **어떤 문제를(문제)** + **어떤 경험으로(근거)** 해결해 주는 사람인지를 **일관되게** 보여 주는 일

화려한 SNS 팔로워 수가 아니라 **일관성**과 **근거**가 핵심입니다.

### 4-3. AI가 잘하는 일 / 사람이 해야 하는 일

| AI에게 맡길 일 | 반드시 내가 할 일 |
|---|---|
| 흩어진 경력을 표로 정리 | 경력·숫자·직함이 **사실인지** 확인 |
| 같은 내용을 길이·채널별로 바꿔 쓰기 | 나다운 말투인지 판단 |
| 콘텐츠 주제 아이디어 뽑기 | 실제로 쓸 수 있는 주제인지 선택 |
| 어색한 문장 다듬기 | 회사 기밀·고객 정보 빼기 |

### 4-4. 토론 질문 (5분)
- "회사 이름을 빼고 나를 소개한다면, 첫 문장은 무엇인가요?"

## 5. 실습 ①: 경험 인벤토리 (AI 인터뷰)

AI에게 **인터뷰어 역할**을 맡겨, 내가 미처 정리하지 못한 경험을 끌어냅니다.

### 프롬프트 (복사해서 사용)
```
너는 4050 직장인의 경력을 정리해 주는 커리어 코치야.
나에게 질문을 하나씩 던져서 내 경험 자산을 찾아 줘.

규칙:
- 한 번에 질문은 1개만 한다.
- 총 7개 질문을 한다. (업무 성과, 위기 해결, 남에게 자주 받는 질문, 가르쳐 본 경험, 숫자로 말할 수 있는 결과, 좋아하는 일, 지금 관심사)
- 7개가 끝나면 내 답변을 아래 표로 정리한다.
  | 경험 | 증거(숫자·사례) | 이 경험이 필요한 사람 |
- 내가 말하지 않은 사실은 지어내지 않는다.
```

### 진행 팁
- 답이 막히면 "예시를 3개 들어 줘"라고 요청해도 됩니다.
- **숫자 하나**(기간·인원·금액·비율)가 들어가면 경험이 곧 근거가 됩니다.
- 회사명·고객명·내부 수치는 "중견 제조사", "약 30% 개선"처럼 **일반화**합니다.

### 산출물 예시
| 경험 | 증거 | 필요한 사람 |
|---|---|---|
| 신입사원 교육 프로그램 운영 | 5년간 120명 교육, 1년 내 퇴사율 40%→15% | 소규모 회사 대표, 신임 팀장 |
| 엑셀 수작업을 자동화 | 월말 마감 3일→반나절 | 회계·총무 담당자 |
| 거래처 클레임 대응 | 연 50건 이상 처리, 재계약률 유지 | 영업 신입, 자영업자 |

## 6. 개념 ②: 포지셔닝 문장과 브랜드 키트

### 6-1. 포지셔닝 문장 공식
```
나는 [대상]이 [문제]를 [방법/경험]으로 [결과]하도록 돕는 [역할]이다.
```
예) 나는 **직원 10명 이하 회사 대표**가 **신입이 자꾸 그만두는 문제**를 **20년 인사 실무 경험**으로 **3개월 안에 정착**하도록 돕는 **조직 적응 코치**다.

### 6-2. 좋은 포지셔닝 문장 체크리스트
- [ ] 대상이 "모든 사람"이 아니라 **구체적인 한 그룹**인가
- [ ] 문제가 대상의 **말투로** 적혀 있는가 ("조직문화 개선" ✕ → "신입이 자꾸 그만둔다" ○)
- [ ] 경험이 **증거**(숫자·사례)로 뒷받침되는가
- [ ] 소리 내어 읽었을 때 **10초 안에** 끝나는가

### 6-3. 브랜드 키트 구성 (오늘의 결과물)

| 항목 | 분량 | 쓰는 곳 |
|---|---|---|
| 한 줄 소개 | 30자 이내 | 카톡 프로필, 명함, 이메일 서명 |
| 30초 자기소개 | 150자 내외 | 모임·네트워킹 |
| 1분 자기소개 | 300자 내외 | 면접, 강의 시작 |
| 온라인 프로필 | 헤드라인 + 소개 500자 | 링크드인, 블로그, 강사 플랫폼 |
| 콘텐츠 주제 기둥 | 3개 × 첫 글 제목 5개 | 블로그·SNS 꾸준히 쓰기 |
| 톤앤매너 | 형용사 3개 + 금지어 | 모든 글의 기준 |

### 6-4. 신뢰와 윤리
- AI는 그럴듯한 **경력·자격증·수치를 지어낼 수 있습니다.** 생성 결과의 모든 사실은 내 이력과 대조합니다.
- "업계 최고", "국내 유일" 같은 **근거 없는 최상급 표현**은 지웁니다. (광고 표현으로 문제 될 수 있음)
- 전 직장의 기밀, 고객 실명, 내부 문서는 프롬프트에 넣지 않습니다.

## 7. 실습 ②: 브랜드 키트 자동 생성

자세한 단계는 [실습 가이드](practice-guide.md)를 따릅니다. 요약:

1. `examples/my_profile.json`에 실습 ①의 경험 인벤토리를 옮긴다.
2. `python brand_kit.py my_profile.json`을 실행한다.
3. 생성된 `output/brand_kit.md`를 열고 **사실 검증 체크리스트**로 고친다.
4. 마음에 들지 않는 항목은 프롬프트의 톤앤매너를 바꿔 다시 생성한다.

> API 키가 없으면 자동으로 **연습 모드**로 동작합니다. 연습 모드에서도 프롬프트가 파일로 저장되므로, 그 프롬프트를 ChatGPT·Claude 웹 화면에 붙여 넣어 같은 실습을 할 수 있습니다.

## 8. 실습 ③: 1페이지 프로필 웹페이지

- `examples/profile_page.html`을 브라우저로 엽니다. (더블클릭)
- 왼쪽 입력칸에 브랜드 키트 문구를 붙여 넣으면 오른쪽 미리보기가 바뀝니다.
- "HTML 복사" 버튼으로 완성본 코드를 복사해, 무료 호스팅(예: 깃허브 페이지, 노션 공개 페이지 임베드)에 올릴 수 있습니다.
- 휴대폰 화면 폭에서도 읽기 편한지 브라우저 창을 좁혀 확인합니다.

## 9. 과제 (8주차 전까지)

1. 브랜드 키트를 **실제 채널 1곳 이상**(카톡 프로필, 링크드인, 블로그 소개)에 적용하고 캡처한다.
2. 콘텐츠 주제 기둥 중 하나로 **첫 글 1편**을 올린다. (AI 초안 → 내 경험 1개 추가 → 발행)
3. 8주차 준비: "내 경험으로 **돈을 받고** 도와줄 수 있는 일" 후보 3개를 적어 온다.

## 10. 강사 노트

- **가장 흔한 막힘**: "저는 내세울 게 없어요." → 실습 ①의 "남에게 자주 받는 질문"부터 시작하게 하면 대부분 풀립니다.
- AI 결과가 모두 비슷해 보이면, 프롬프트에 **실패담 1개**를 넣게 합니다. 실패와 회복 경험이 차별점이 됩니다.
- 코드를 처음 실행하는 분은 짝꿍과 한 화면으로 진행합니다. 실행이 어려우면 `output/brand_kit_prompt.txt` 내용을 웹 AI에 붙여 넣는 방식으로 대체합니다.
- 개인정보: 실명·연락처는 마지막 단계(HTML)에서만 본인이 직접 입력하도록 안내합니다.
